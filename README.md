# Unity Engine Test Model 🎮

A small Unity game I built to learn, experiment, and have fun with game development.

This project is part of my journey into Unity and C#. I used it to explore core game development concepts such as player movement, physics, collisions, UI, scene management, and gameplay mechanics.

It may be a test project, but everything here was built by me from the ground up—along with a few bugs that became unexpected features.

## Built With

- Unity
- C#
- Unity Physics
- Unity UI

## What I Learned

- Creating player controls and movement
- Working with colliders and rigidbodies
- Managing scenes and game states
- Building simple UI elements
- Debugging code until it finally behaves

Still a work in progress. I’ll keep updating it as I learn more and add new ideas.
